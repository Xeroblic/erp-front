# QWEN.md - Project Context

## Project Overview

- **Name**: ERP Front
- **Type**: Frontend Application
- **Framework**: Vue.js (based on typical ERP front-end structure)

## Development Guidelines

- Follow existing code style defined in `.eslintrc.json` and `.prettierrc`
- Use TypeScript/JavaScript conventions consistent with the codebase
- Ensure all components are properly typed
- Write tests for new features and bug fixes

## Key Files

- `.env`, `.env.development`, `.env.production`: Environment configurations
- `package.json`: Dependencies and scripts
- `index.html`: Entry point
- `.eslintrc.json`: ESLint configuration
- `.prettierrc`: Prettier configuration

## Commands

- Install dependencies: `npm install` or `yarn install`
- Run development server: Check `package.json` for dev script
- Build for production: Check `package.json` for build script
- Run tests: Check `package.json` for test script
