## 🔄 Lógica de Negocio Implementada

### **Reversión + Aplicación (Ajuste Neto)**

```typescript
// 1. REVERTIR movimiento anterior
if (originalMovement.movement_type === 'IN' || originalMovement.quantity > 0) {
	// Si era entrada, restar para revertir
	originalStockItem.current_stock -= Math.abs(originalMovement.quantity);
} else {
	// Si era salida, sumar para revertir
	originalStockItem.current_stock += Math.abs(originalMovement.quantity);
}

// 2. APLICAR nuevo movimiento
newStockItem.current_stock += finalQuantity;

// 3. ACTUALIZAR estados y metadatos
newStockItem.status = calculateStatus(newStockItem.current_stock);
newStockItem.last_updated = new Date().toISOString();
```
