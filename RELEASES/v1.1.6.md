# Zentria ERP - Versión v1.1.6

**Fecha de Lanzamiento:** 09 de Marzo, 2026

## Resumen de la Versión

Esta versión marca el primer hito de Zentria ERP, consolidando la infraestructura base del
frontend y desplegando módulos críticos para la operación logística y técnica. La versión
1.1.6 está completamente sincronizada con las capacidades del Core Backend v1.1.6 como
lanzamiento inicial. A partir de aquí el frontend toma su versionado independiente del core.

## Funcionalidades Destacadas

### Módulo de Revisiones Técnicas (Core)

- **Flujo Standalone y por Lotes:** Capacidad de procesar equipos de forma individual o
  agrupados en batches.
- **Formularios Dinámicos:** Validaciones específicas según el tipo de equipo (Notebook,
  Desktop, AIO, Monitor, Docking).
- **Sistema de Scoring Automático:** Integración con el motor de calificación del backend para
  sugerir grados (A, B, C, D, M) basados en el estado técnico.
- **Auto-Guardado Inteligente:** Persistencia del progreso cada 30 segundos para evitar
  pérdida de datos en formularios extensos.

### Refactorización de Integraciones

- **WooCommerce 2.0:** Gestión centralizada de claves API, Webhooks y mapeo de productos.
- **Sincronización de Stock:** Motor para reflejar existencias del ERP en tiendas online en
  tiempo real.
- **Importación de Órdenes:** Flujo automatizado para convertir pedidos de e-commerce en
  órdenes de despacho internas.

### Seguridad y Control de Acceso (RBAC)

- **Sistema de Permisos (Authority):** Validación granular de acciones basada en roles
  corporativos.
- **Permission Guards:** Componentes de UI que se adaptan dinámicamente según los privilegios
  del usuario.
- **Gestión de Sucursal Preferida:** Selector global que filtra toda la data del sistema
  según la sucursal activa.

## Stack Tecnológico

- **Core:** React 18.3 + TypeScript 5.4
- **Bundler:** Vite 5 + SWC
- **Estado:** Redux Toolkit con persistencia local
- **Formularios:** Formik + Yup
- **Estilos:** Tailwind CSS 3 con sistema de temas corporativos reactivos
- **Tablas:** TanStack Table v8
