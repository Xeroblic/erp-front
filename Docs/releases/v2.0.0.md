# Zentria ERP - Versión v2.0.0

**Fecha de Lanzamiento:** 09 de Julio, 2026

## Resumen de la Versión

La versión v2.0.0 es el mayor release de Zentria ERP desde su lanzamiento inicial. Consolida
todo el trabajo acumulado en `develop` desde v1.6.0 (incluyendo el Release Candidate
v1.7.0-rc.1) y marca la integración definitiva de `develop` → `main`.

Los pilares de esta versión son:

1. **Suite completa de WooCommerce** — sincronización bidireccional de productos, overrides
   por canal, diagnóstico en tiempo real, emparejamiento manual y gestión de webhooks.
2. **Refactor profundo de arquitectura de contexto** — centralización del switch
   organizacional, tipado estricto de interfaces contra el contrato real del backend, y
   eliminación de código legacy/deprecated.
3. **Mejoras en el flujo de ventas** — cierre de ventas con `can_close`, inventario
   finalizado (`inventory_finalized`), corrección y confirmación de series, devoluciones
   físicas y modales apilables.
4. **Nuevo sistema de pestañas de producto** — revisiones técnicas por producto, overrides de
   precio/nombre/visibilidad por canal y diagnóstico ERP vs WooCommerce.

## Nuevas Funcionalidades

### WooCommerce — Integración de Productos

- **Sincronización ERP ↔ WooCommerce:** publicación, despublicación y actualización de
  productos con toggle de sincronización y advertencia destructiva (papelera) al apagar. (#28,
  #55)
- **Emparejamiento manual:** buscador de candidatos en WooCommerce con comparación lado a lado
  (nombre, SKU, precio), decisión consciente de SKU (`sku_resolution`), resolución de imagen,
  importación de descripción y sincronización de stock al vincular. (#62, #65, #58, #60)
- **Hub unificado con pestañas:** selector de integración, panel de sincronización,
  configuración de overrides por canal y diagnóstico, todo en un layout de dos columnas
  limpio y neutral. (#35, #67, #89)
- **Overrides por canal:** precio, nombre y visibilidad personalizables por integración de
  WooCommerce, con switch de visibilidad pública/privada que resuelve correctamente
  `effective_visibility`. (#67, #89)
- **Diagnóstico en tiempo real:** consulta del estado remoto del producto en la tienda con
  tabla comparativa de Estado, Precio y Stock, badges de discrepancia. (#89)
- **Tabla comparativa de productos vinculados:** la página de productos WooCommerce ahora
  compara campos homólogos (ID, SKU, Nombre, Precio, Oferta) del ERP contra los remotos con
  alertas de discrepancia visual. (#89)
- **Guía visual de sincronización:** se muestra automáticamente la primera vez que se abre el
  panel y queda accesible mediante botón de ayuda. (#56)

### Integraciones / Webhooks

- **Importación de términos** (categorías/marcas) desde WooCommerce con opción de deshacer.
  (#27, #50)
- **Toggle rápido de activación** en la lista de integraciones. (#39)
- **Catálogo de webhooks entrantes** expuesto en el modal de configuración. (#48)
- **Desvinculación masiva** de productos WooCommerce (solo super-admin). (#49)
- **Registro de webhook** para el evento de productos (`product.updated`). (#63)

### Ventas

- **Flujo de cierre de venta:** el botón de "Cerrar venta" se rige exclusivamente por el
  campo `can_close` del backend. (#89)
- **Inventario finalizado:** badge de "Finalizada" cuando `inventory_finalized` es `true`, con
  inventario en modo solo lectura (bloquea corrección de series y confirmación de
  devoluciones físicas). (#89)
- **Confirmación de devolución y corrección de series:** nuevos flujos modales con escaneo de
  series, validación de cantidades y modales apilables con blur. (#70)
- **Bandeja de ventas pendientes de asignar serie** con badge indicador. (#47)
- **Cierre de ventas con series mixtas.** (#46)

### Productos / Catálogo

- **Pestaña de revisiones por producto** en el detalle, con consulta de series del producto
  padre. (#68, #72)
- **Soft-holds (apartados):** visibilidad de apartados en productos y ventas. (#51)
- **Ajuste de stock:** buscador del catálogo encuentra por SKU con mejora UX/UI. (#52)

### Contexto Organizacional (Refactor Mayor)

- **Centralización del switch de contexto** en `useOrgContextSwitcher`, eliminando
  `useUserBranches` deprecated. (#74, #76, #78)
- **Interfaces alineadas al backend:** `ISucursal`/`IBranch` (#87), `ISubempresa` (#84),
  `IAdminUser` (#81, #83), `IUserMe` (#79) ahora reflejan el contrato real del API.
- **Limpieza de `useCompanyManager`:** tipado estricto sin `any` ni `console`. (#88)
- **Separación de `sucursal_principal` vs `subsidiary_id`** en el switch de contexto. (#86)
- **`normalizeUserProfile`:** garantiza que `id` siempre exista (mapea `pk` → `id`). (#79)

### UI / UX

- **Modal con indicador de scroll** y restyle de acciones en ventas/cotizaciones. (#71)
- **Modales apilables con blur** y Escape limitado al modal superior. (#apilados)
- **Checkbox "Recordar cuenta"** funcional en login. (#42)
- **Botón "No Enciende"** para categorización rápida M en revisión técnica. (#25)
- **Mejoras UX/UI** de categorías e imágenes. (#31)

## Corrección de Errores

- **RichText:** elimina el `<br>` sobrante que rompía el espaciado en WooCommerce. (#61)
- **Candidatos Woo:** normaliza stock y estado de vínculo en el buscador. (#59)
- **Revisión técnica:** "Recalcular" muestra el nuevo grado sugerido, no el actual. (#53)
- **Precios Woo:** compara numéricamente para evitar falso "Difiere". (#43)
- **Sesión JWT:** evita cierre de sesión por refresh fallido al expirar el token. (#41)
- **Wrapper `data`:** desempaqueta correctamente los productos sincronizados. (#38)
- **Visibilidad privada:** el switch de visibilidad ahora resuelve `effective_visibility`
  correctamente cuando el canal está en `private`. (#89)
- **Series de venta:** escanear series usa la cantidad total del ítem. (fix inline)
- **Estados de revisión:** corrección y limpieza en la pestaña de revisiones. (#69)

## Migración y Notas de Actualización

### Para actualizar a v2.0.0:

```bash
git fetch --tags
git checkout main
git pull origin main
# El merge de develop → main se realiza mediante el PR correspondiente
```

### Cambios de interfaz importantes (Breaking Changes potenciales):

| Interfaz anterior        | Interfaz nueva                                 | PR       |
| ------------------------ | ---------------------------------------------- | -------- |
| `IUser` genérico         | `IAdminUser` + `IUserMe` separados             | #81, #83 |
| `useUserBranches`        | `selectUserBranches` (selector Redux)          | #76      |
| `useOrgContext` disperso | `useOrgContextSwitcher` centralizado           | #74, #78 |
| `ISubempresa` ad-hoc     | `ISubempresa` alineada al backend              | #84      |
| `ISucursal` ad-hoc       | `ISucursal`/`IBranch` alineadas                | #87      |
| `visibility` en canal    | `effective_visibility` + `visibility_override` | #89      |

### Versionado:

- La versión del proyecto se incrementa de `1.7.0-rc.1` a `2.0.0` en `package.json`.
- Este release **reemplaza** al Release Candidate `v1.7.0-rc.1` y lo incluye por completo.
- A partir de esta versión, `main` y `develop` quedan sincronizados.
