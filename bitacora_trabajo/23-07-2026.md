# Bitácora — 23-07-2026

## Sesión 11:00 – 13:30 · rama `feat/no-tiene-ram-disco-revisiones` (creada desde `develop`)

Objetivo: **agregar opciones "No tiene RAM" y "No tiene disco" en formularios de hardware de revisiones técnicas**.

### Planificación y exploración

- Se exploró el módulo `src/pages/refactor-technical-review/` para mapear campos `ram_size`, `ram_slots`, `ram_type`, `storage_size`, `storage_technology` en los 3 tipos de equipo (notebook, desktop, AIO).
- Se identificó que el flujo "No enciende" ya usa el sentinel `'0'` para estos campos. Se decidió reutilizarlo como contrato.
- **Decisión:** `storage_technology` no se fuerza a valor dummy cuando no hay disco; se limpia con `undefined` (el backend lo omite). Para `ram_type` cuando no hay RAM, se limpia con `''`.

### Infraestructura

- **[feat]** `constants/shared/hardware.sentinels.ts` — constante `'0'`, helper `isHardwareAbsent()`, label `"No tiene"`.
- **[feat]** `forms/shared/NoHardwareToggle.tsx` — botón toggle reutilizable (estados activo/inactivo, borde punteado/rojo, badge "Activo", ícono condicional).

### Validación — Yup (3 schemas)

- **[feat]** `ram_type` y `ram_slots` pasan a `.when('ram_size', { is: '0', then: nullable })` en notebook, desktop y aio.
- **[feat]** `storage_technology` pasa a `.when('storage_size', { is: '0', then: nullable })` en los 3 schemas.
- **[fix]** QA detectó que `ram_slots` seguía `required` incondicional: si backend devolvía `ram_size='0'` sin slots, el submit fallaba con el campo oculto por el toggle. Corregido con `.when()`.

### UI — HardwareSection × 3

- **[feat]** Toggle `NoHardwareToggle` en cada card de RAM y Almacenamiento (notebook, desktop, AIO).
- Cuando activo: oculta inputs y muestra "Equipo sin memoria RAM" / "Equipo sin disco de almacenamiento". Oculta asterisco `*` de requerido.
- `onToggle` inline setea `ram_size='0'`, `ram_slots='0'` / `storage_size='0'`, `storage_technology=undefined`. Al desactivar, limpia los campos.
- Hidratación: `isHardwareAbsent(watch('ram_size'))` → toggle ON al cargar datos existentes.

### Display — 4 capas

- **[feat]** `reviewTranslations.ts`: `translateValue` y `extractValue` → string `'0'` → `"No tiene"` (no afecta número `0` de puertos por ser strict equality).
- **[feat]** `PrintLabel.tsx`: `formatRamLabel()` evita sufijo `GB` cuando es ausente. `extractValue` local mapea `'0'`.
- **[fix]** QA detectó que la etiqueta mostraba `"No tiene HDD"` porque concatenaba `storage_technology` aunque no hubiera disco. Corregido: solo renderiza tecnología si `!isHardwareAbsent(storage_size)`.
- **[feat]** `exportExcel.ts`: `normalizeDetailValue` → `isHardwareAbsent` antes del resto de normalización.
- **[feat]** `InputUnitSelector.tsx`: early return en `useEffect` si value es `'0'` (no parsea `0GB`).

### Compatibilidad

- **NoEnciende:** se simplificó `onValidate` (ya no exige `storage_technology`), usa variables del componente en vez de re-declarar con `watch()` (evita shadow lint).
- **Autosave:** `cleanData` de `reviewThunks` no strippea `'0'` (solo `null`, `undefined`, `''`).
