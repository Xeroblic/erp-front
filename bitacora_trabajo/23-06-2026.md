### Detalle técnico — Hub de Integraciones

**Decisión de arquitectura:** En vez de añadir un 6.º item de menú suelto, se creó una sola página "Integraciones" con pestañas lazy (solo monta la pestaña activa vía `useSearchParams`). Restricciones descubiertas: `PageWrapper` no puede anidarse (daría `<main>` anidado), y tener dos `Subheader` sticky se solaparían — la barra de tabs quedó no-sticky.

**Refactor:** Cada página existente se partió en un `XContent` (JSX sin PageWrapper, para el hub) y un `export default XPage` (wrapper fino para rutas standalone sin regresión).

**Convención de botones aplicada:**
| Rol | Estilo |
|-----|--------|
| Primaria (crear/importar/sincronizar) | `solid` sin color (hereda marca del tema) |
| Secundaria/neutra (refrescar/limpiar) | `outline` `zinc` |
| Sync por fila (precio/stock/variaciones) | `outline` `zinc` (se distinguen por ícono + tooltip) |
| Ver / Detalle | `outline` `violet` |
| Editar | `outline` `sky` |
| Eliminar / Cancelar | `outline`/`solid` `red` |
